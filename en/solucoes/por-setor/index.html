Why by sector

Same modules, different order.

Different sectors have different pains, but the platform does not change: what changes is where it makes sense to start and what comes next.

Start with what weighs most

Each sector has a more common starting point. Each sector's page indicates which modules usually come in first.

Grow module by module

The modules share the same data. When the second comes in, it already knows what the first recorded.

Not locked into one slice

Sector is an entry point, not a restriction. The same modules serve any combination.
